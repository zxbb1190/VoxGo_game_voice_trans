VoxGo 0.6.1

2026-11-18

本页内容由 GitHub Release 生成。

更新内容

  1. 现在可以看电影字幕了：译文在上，原文小字在下。按 Ctrl+Alt+M 即可切换。
  2. 可以只翻译选中的游戏或应用，让字幕只显示你想听的内容。
  3. 没有字幕时，在「设置 → 帮助与反馈」点「自动检测」即可查找原因。
  4. 使用 0.6.0 Lite？请到官网下载新版 Lite，避免下载较大的完整包。
  5. 修复已知问题。

What's new

  1. Cinema subtitles show the translation above a smaller original line. Press Ctrl+Alt+M to switch.
  2. Choose a game or app to see subtitles only for its audio.
  3. Missing subtitles? Open Settings → Help & Feedback and run Automatic diagnostics.
  4. Using 0.6.0 Lite? Download Lite from the website to avoid downloading the larger Full edition.
  5. Fixed known issues.

Lite 升级 / Updating Lite

0.6.0 Lite 的自动更新有时会选中完整包。如需保留 Lite，请在官网下载新版 Lite；国内镜像请认准 v0.6.1。先从托盘退出 VoxGo，备份原安装目录，再将压缩包内的 VoxGo.exe 和同级文件解压到原 VoxGo.exe 所在目录。保留原有设置和模型文件；自行修改过的配置可从备份恢复。

The 0.6.0 Lite updater may select Full. To keep Lite, download the new Lite ZIP from the website. For the China mirror, look for v0.6.1. Quit VoxGo from the tray and back up the installation folder. Extract VoxGo.exe and its accompanying files into the folder containing the existing VoxGo.exe. Keep your settings and models, and restore any custom configuration from the backup.
