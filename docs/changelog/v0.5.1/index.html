VoxGo 0.5.1

2026-09-23

本页内容由 GitHub Release 生成。

更新内容

  1. 音频设备异常后自动恢复：重新检测 USB、蓝牙和 HDMI 输出，优先恢复原设备，必要时回退系统默认输出，并显示恢复状态。
  2. 浮窗位置自动恢复：屏幕配置变化后自动找回不可见浮窗，托盘新增重置浮窗位置。
  3. 浮窗显示当前翻译方式：API、Google 或本地，切换后立即更新。
  4. 字幕支持悬停复制：鼠标移入正常字幕后可一键复制译文。
  5. 首次启动跟随系统语言：zh_CN、zh_TW 使用中文，其他语言使用英文；已有用户设置保持不变。
  6. 更新使用统计：基础统计始终启用，用于每日活跃安装数，使用不跨日关联的每日标识；详细使用与稳定性统计可在设置中关闭，均不包含语音、识别或翻译内容。升级时保留统计状态。

What's new

  1. Automatic audio recovery: detect USB, Bluetooth, and HDMI output changes, reconnect the original device or fall back to the system default, and show recovery status.
  2. Overlay position recovery: bring an invisible overlay back after display changes, with a new Reset Overlay Position tray action.
  3. The overlay now shows the current translation provider: API, Google, or Local, updating immediately after a switch.
  4. Hover over a completed subtitle to copy its translation with one click.
  5. First launch follows the system language: Chinese for zh_CN and zh_TW, English for all other locales. Existing language preferences are preserved.
  6. Updated usage statistics: Basic is always enabled and measures daily active installations using daily identifiers that are not linked across days. Optional detailed usage and stability statistics can be disabled in Settings; neither includes audio, recognition, or translation content. Updates preserve statistics state.
