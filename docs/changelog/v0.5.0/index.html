VoxGo 0.5.0

2026-09-21

本页内容由 GitHub Release 生成。

更新内容

  1. 优化关闭与托盘体验：关闭窗口时可选择最小化到托盘或退出程序，并记住选择；托盘不可用时保留窗口，避免程序隐藏后无法操作。
  2. 改进退出流程：优化后台任务与资源清理，退出未完成时支持重试或强制退出，改善窗口关闭后进程残留的问题。
  3. 新增模型恢复操作：模型加载失败时，可在设置中重试加载，或重置所选模型缓存后重新下载。
  4. 完善帮助与反馈：支持预览、复制诊断信息并打开 GitHub Issues，诊断模板减少敏感信息暴露。
  5. 新增自愿体验改进计划：经确认后发送使用情况与运行稳定性统计，帮助优化 VoxGo；不包含语音、识别或翻译内容，可随时在设置中关闭。

What's new

  1. Improved close and tray behavior: choose to minimize to the tray or exit when closing the window, with the choice remembered; the window remains available if the tray is unavailable.
  2. Improved shutdown: background tasks and resources are cleaned up more safely, with retry or force-exit options when shutdown cannot finish, reducing residual processes after closing the window.
  3. Added model recovery: retry loading a failed model from Settings, or reset the selected model cache and download it again.
  4. Improved Help and Feedback: preview and copy diagnostic information, open GitHub Issues, and use diagnostic templates that reduce sensitive-data exposure.
  5. Added an opt-in experience-improvement program: after consent, VoxGo sends usage and stability statistics to help improve the app. It never includes audio, recognition, or translation content, and can be disabled at any time.
