VoxGo 0.5.2

2026-10-06

本页内容由 GitHub Release 生成。

更新内容

  1. 修复部分实时语音在停顿后可能被错误切分的问题。
  2. 增强语音识别异常保护，减少强噪声下出现异常重复字幕的情况。
  3. 改进聚合诊断信息，便于定位运行问题；诊断信息不包含语音、识别或翻译内容。
  4. 设置中的帮助与反馈新增 KOOK 和 Discord 社区入口，并保留 GitHub Issues。

What's new

  1. Fixed cases where real-time speech audio could be segmented incorrectly after a pause.
  2. Strengthened speech recognition safeguards to reduce abnormal repeated captions under heavy noise.
  3. Improved aggregated diagnostic information for investigating runtime issues; diagnostics do not include audio, recognition, or translation content.
  4. Added KOOK and Discord community links to Help & Feedback in Settings, while keeping GitHub Issues.
