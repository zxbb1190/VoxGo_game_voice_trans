# VoxGo v0.5.3

Release Candidate draft — not published. 正式发布前仍须完成生产迁移和部署验收。

2026-10-28 多语言候选：支持中/英/日/韩/俄五语之间20个有向在线翻译方向，软件界面也支持这五种语言。新增语种质量仍待独立验收；本草稿不是发布批准。

## 更新内容

- 在用户允许完整匿名遥测时，按 Fast、Balanced、Accurate 和 Custom 模式分别统计 ASR 切段数量、强制切段、短片段及片段时长，帮助定位不同模式下的问题。
- 增加 API 翻译失败的固定原因分类：超时、网络、限流、HTTP 错误、空结果及其他；同时区分 Google 与 OpenAI 兼容服务商。
- 对应管理 Dashboard 展示分模式 ASR 指标、分类上报覆盖和 API 失败分类；历史未分类数据继续保留原口径。
- 分类诊断继续遵守 Full 授权规则，仅上报固定聚合数值，不上报语音、字幕、API Key、请求地址或错误正文。
- 支持中文（普通话识别）、英语、日语、韩语、俄语五语之间20个有向在线翻译候选；保留原有英中双向离线。语言选择、检测过滤、在线请求和翻译 Prompt 按实际方向工作，不经英语中转。
- 软件界面新增日语、韩语、俄语，包含设置、浮窗、首次配置、下载/更新、错误和退出提示、隐私及帮助。界面语言独立保存，不改变语音识别或翻译方向；原文、实际译文和外部错误详情保持原样。
- 中文译其他语言时，浮窗和手机镜像中的识别原文统一显示简体；Whisper 原始结果、过滤规则、送翻译文本及实际译文保持不变。
- 日/韩/俄使用现有多语言 Whisper；英语专用 `.en` 模型会明确提示不兼容。在线翻译需用户自行配置 API Key，本地 OPUS 仍仅支持英中，不能自动切换到其他语言或在线服务。
- 日/韩/俄统一使用兼容识别策略，正式设置界面移除候选策略开关；旧配置中的候选值不再启用实验参数。语种切换在下一段推理前安全更新模型，清理旧方向待处理内容；已有性能档位和自定义调校保留。

不增加新语言离线模型，保留现有英中本地翻译策略、中英识别配置、正式ASR预设及ASR Prompt。新语种策略使用现有base/small模型，不增加运行依赖。多语言人工质量、真实游戏与低配设备验收未完成，且仍存在识别、术语和延迟问题，当前不能作为正式可发布版本。

## What's new

- With Full anonymous telemetry enabled, ASR diagnostics now separate Fast, Balanced, Accurate and Custom modes, including segment counts, forced cuts, short fragments and segment duration.
- Added fixed API translation failure categories: timeout, network, rate limit, HTTP error, empty result and other, with separate Google and OpenAI-compatible provider counters.
- Updated the admin Dashboard with per-mode ASR metrics, classification reporting coverage and API failure breakdowns. Historical unclassified data keeps its existing meaning.
- Classified diagnostics remain subject to Full consent and contain fixed aggregate numbers only, without audio, captions, API keys, request addresses or error bodies.
- Supports 20 directed online translation pairs across Chinese (Mandarin speech), English, Japanese, Korean and Russian, while retaining offline English–Chinese translation. Language selection, filtering, provider requests and translation prompts use the actual direction without an English pivot.
- Added Japanese, Korean and Russian interface languages across settings, the overlay, setup, download/update, error/exit notices, privacy and help. Interface language is saved separately from speech/translation directions; source speech text, real translations and external error details remain unchanged.
- Chinese speech translated into other languages now displays its source transcript in Simplified Chinese in the overlay and mobile mirror. Raw Whisper results, filtering, translation input and translated output are unchanged.
- New source languages require a multilingual Whisper model and user-configured API credentials. English-only `.en` models show an explicit limitation. Local OPUS remains English–Chinese only; no automatic language or provider substitution.
- Japanese, Korean and Russian use the compatibility recognition policy. Removed the candidate strategy switch from Settings; old candidate preferences no longer enable experimental overrides. Language changes apply model settings between inferences and discard stale work. Existing performance modes and custom tuning remain available.

No new offline language models or runtime dependencies. English–Chinese recognition settings, OPUS behavior, formal ASR presets and ASR prompts are unchanged; the new-language strategy reuses existing base/small models. Recognition, terminology and latency issues remain. Bilingual human review, real game scenarios and low-end device acceptance are incomplete; the multilingual candidate is not release-approved.
