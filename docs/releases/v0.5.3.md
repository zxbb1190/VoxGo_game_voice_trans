# VoxGo v0.5.3

Release Candidate draft — not published. 正式发布前仍须完成生产迁移和部署验收。

## 更新内容

- 在用户允许完整匿名遥测时，按 Fast、Balanced、Accurate 和 Custom 模式分别统计 ASR 切段数量、强制切段、短片段及片段时长，帮助定位不同模式下的问题。
- 增加 API 翻译失败的固定原因分类：超时、网络、限流、HTTP 错误、空结果及其他；同时区分 Google 与 OpenAI 兼容服务商。
- 对应管理 Dashboard 展示分模式 ASR 指标、分类上报覆盖和 API 失败分类；历史未分类数据继续保留原口径。
- 分类诊断继续遵守 Full 授权规则，仅上报固定聚合数值，不上报语音、字幕、API Key、请求地址或错误正文。

本版本不包含新语言离线翻译或翻译策略调整，不修改正式 ASR 模型、切段参数或 Prompt。

## What's new

- With Full anonymous telemetry enabled, ASR diagnostics now separate Fast, Balanced, Accurate and Custom modes, including segment counts, forced cuts, short fragments and segment duration.
- Added fixed API translation failure categories: timeout, network, rate limit, HTTP error, empty result and other, with separate Google and OpenAI-compatible provider counters.
- Updated the admin Dashboard with per-mode ASR metrics, classification reporting coverage and API failure breakdowns. Historical unclassified data keeps its existing meaning.
- Classified diagnostics remain subject to Full consent and contain fixed aggregate numbers only, without audio, captions, API keys, request addresses or error bodies.

This release does not add offline translation languages or change translation strategies, production ASR models, segmentation parameters or prompts.

## 构建与发布 / Build and publish

The RC is built locally from the isolated release branch. D1 migration 0006 and a compatible Worker must be accepted before distributing the client. Keep the published update manifest at v0.5.2 until the final assets are published and verified.

```powershell
# Local packaging only: Lite, Full, Full-CUDA and CUDA runtime.
.\scripts\build_portable.ps1 -Version "0.5.3"
.\.venv-win\Scripts\python.exe scripts\release_preflight.py --version 0.5.3 --base-ref 52d77cbf

# FUTURE, separately authorized publication only. NOT executed during RC work.
# Pushing this tag triggers the GitHub release workflow.
git tag v0.5.3
git push origin v0.5.3
```

Migration, Worker deployment, Git push and GitHub Release are outside this RC run. See `docs/testing/release-v0.5.3-rc.md` for validation evidence and the operator checklist. No production writes are required to repeat the local acceptance.
