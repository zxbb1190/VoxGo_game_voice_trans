# VoxGo v0.5.3

Release Candidate draft — not published. 正式发布前仍须完成生产迁移和部署验收。

2026-10-21 多语言在线候选：语言框架和技术回归已扩展，日/韩/俄及中文→日语质量仍待独立验收；本草稿不是发布批准。

## 更新内容

- 在用户允许完整匿名遥测时，按 Fast、Balanced、Accurate 和 Custom 模式分别统计 ASR 切段数量、强制切段、短片段及片段时长，帮助定位不同模式下的问题。
- 增加 API 翻译失败的固定原因分类：超时、网络、限流、HTTP 错误、空结果及其他；同时区分 Google 与 OpenAI 兼容服务商。
- 对应管理 Dashboard 展示分模式 ASR 指标、分类上报覆盖和 API 失败分类；历史未分类数据继续保留原口径。
- 分类诊断继续遵守 Full 授权规则，仅上报固定聚合数值，不上报语音、字幕、API Key、请求地址或错误正文。
- 新增日语、韩语、俄语→中文的在线翻译候选，并补充中文→日语方向；保留原有英中双向。语言选择、检测过滤、在线请求和翻译 Prompt 按实际方向工作，不经英语中转。
- 日/韩/俄使用现有多语言 Whisper；英语专用 `.en` 模型会明确提示不兼容。在线翻译需用户自行配置 API Key，本地 OPUS 仍仅支持英中，不能自动切换到其他语言或在线服务。

不增加新语言离线模型，保留现有英中本地翻译策略、正式 ASR 模型、切段参数和 ASR Prompt。多语言人工质量、真实游戏与低配设备验收未完成，当前不能作为正式可发布版本。

## What's new

- With Full anonymous telemetry enabled, ASR diagnostics now separate Fast, Balanced, Accurate and Custom modes, including segment counts, forced cuts, short fragments and segment duration.
- Added fixed API translation failure categories: timeout, network, rate limit, HTTP error, empty result and other, with separate Google and OpenAI-compatible provider counters.
- Updated the admin Dashboard with per-mode ASR metrics, classification reporting coverage and API failure breakdowns. Historical unclassified data keeps its existing meaning.
- Classified diagnostics remain subject to Full consent and contain fixed aggregate numbers only, without audio, captions, API keys, request addresses or error bodies.
- Added candidate online Japanese, Korean and Russian to Chinese translation, plus Chinese to Japanese, while retaining English–Chinese translation. Language selection, filtering, provider requests and translation prompts use the actual direction without an English pivot.
- New source languages require a multilingual Whisper model and user-configured API credentials. English-only `.en` models show an explicit limitation. Local OPUS remains English–Chinese only; no automatic language or provider substitution.

No new offline language models, English–Chinese OPUS strategy changes, ASR model tuning, segmentation changes or ASR prompt changes. Bilingual human review, real game scenarios and low-end device acceptance are incomplete; the multilingual candidate is not release-approved.
