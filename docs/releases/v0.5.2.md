# VoxGo v0.5.2

## 更新内容

- 修复部分实时语音在停顿后可能被错误切分的问题。
- 增强语音识别异常保护，减少强噪声下出现异常重复字幕的情况。
- 增加聚合诊断指标，辅助了解切段与识别过滤情况。
- 设置的帮助与反馈新增 KOOK、Discord 社区入口，并保留 GitHub Issues。

## What's new

- Fixed cases where real-time speech audio could be segmented incorrectly after a pause.
- Strengthened speech recognition safeguards to reduce abnormal repeated captions under heavy noise.
- Added aggregate diagnostic metrics for segmentation and recognition filtering.
- Added KOOK and Discord links to Help & Feedback in Settings, while keeping GitHub Issues.

## 构建与发布 / Build and publish

Run from the Windows repository root after installing `requirements.txt` and preparing the CUDA runtime as required:

```powershell
# Build Lite, Full, Full-CUDA, and the CUDA runtime archive.
.\scripts\build_portable.ps1 -Version "0.5.2"

# Build one edition only.
.\scripts\build_portable.ps1 -Version "0.5.2" -SkipFull -SkipFullCuda -SkipCudaRuntimeZip
.\scripts\build_portable.ps1 -Version "0.5.2" -SkipLite -SkipFullCuda -SkipCudaRuntimeZip
.\scripts\build_portable.ps1 -Version "0.5.2" -SkipLite -SkipFull -SkipCudaRuntimeZip

# Run the read-only release preflight before creating a tag.
.\.venv-win\Scripts\python.exe scripts\release_preflight.py --version 0.5.2 --base-ref origin/main

# Pushing this tag triggers the GitHub release workflow.
git tag v0.5.2
git push origin v0.5.2
```

The three single-edition commands build Lite, Full, and Full-CUDA respectively. The GitHub workflow publishes all editions and then advances release metadata after the matching assets are available.
