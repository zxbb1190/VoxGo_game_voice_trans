# VoxGo v0.6.1

## 更新内容

- 新增电影字幕模式：上方显示译文，下方用小字显示原文。可以从工具栏切换，也可以按默认快捷键 Ctrl+Alt+M。原有用户继续使用经典浮窗，直到主动切换。
- Lite 从本版起按安装包标记更新，已下载模型也不会变成 Full。在更新窗口可选 GitHub 或已校验的同版本国内镜像（GitCode）；下载慢时可取消并换源。
- 收音设置新增「只翻译指定应用」；默认仍使用原来的系统音源。遇到没有字幕等问题时，可在「设置 → 帮助与反馈 → 自动检测」检查模型、收音、识别、翻译和显示。
- 首次引导中，如果在线 API 尚未配置或所选本地翻译模型尚未下载，可以返回准备或继续跳过。保留旧设置升级时，已完成引导的用户不会重走引导。
- 成功翻译后可以看到社区邀请；点「不再显示」后，后续保留设置升级也不会再出现。
- 从 0.6.0 Lite 升级：旧版可能下载较大的 Full 包。想保留 Lite 或国内下载慢，请在官网 voxgo.cn 选择标有 v0.6.1 的国内 Lite 镜像；若仍标旧版，请选 GitHub Lite 或等待镜像同步。退出 VoxGo（含托盘）、备份旧目录，将 ZIP 内 VoxGo.exe 和同级文件覆盖到原 VoxGo.exe 所在目录，保留 user_settings.json 和模型缓存。若自行修改过配置文件，请从备份恢复自定义项。

## What's new

- Cinema subtitles show the translation above a smaller original line. Switch using the toolbar or Ctrl+Alt+M by default. Existing users keep the classic overlay until they switch.
- Lite now uses its installed edition marker, so downloaded models no longer change which update it gets. Choose GitHub or the verified GitCode mirror for the same Lite release. Cancel a slow download to switch sources.
- Audio settings can capture a selected application. System audio remains the default. If subtitles are missing, open Settings → Help & Feedback → Automatic diagnostics to check model readiness, audio, recognition, translation and display.
- First-time setup lets you configure a missing online API or download a missing local translation model, or skip for now. Upgrading with existing settings keeps completed setup.
- A community invitation is available after a successful translation. Choosing “Do not show again” is remembered across updates that keep your settings.
- Upgrading from 0.6.0 Lite? The old updater may download Full. To stay on Lite or avoid a slow download, visit voxgo.cn and choose the China Lite mirror marked v0.6.1. If it still shows an older version, use GitHub Lite or wait for the mirror. Quit VoxGo from the tray, back up the installation directory, and extract the contents alongside the existing VoxGo.exe, keeping user_settings.json and the model caches. Restore any custom configuration changes from the backup.

## 构建与发布 / Build and publish

GitHub 发布四类附件，GitCode 只镜像同一份 Lite。须保留 GitHub Full 附件供已运行的 0.6.0 更新器使用。镜像未回读校验时不写入客户端清单。

```powershell
.\scripts\build_portable.ps1 -Version "0.6.1"
# 仅在正式发布获准后执行：
git tag v0.6.1
git push origin v0.6.1
```
