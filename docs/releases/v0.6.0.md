# VoxGo v0.6.0

Unreleased multilingual Beta draft — not published. 多语言 Beta 待发布草稿，尚未发布；公开下载及更新清单仍为 v0.5.2。

This version supersedes the unreleased 0.5.3 multilingual candidate. Historical 0.5.3 reports and experiments retain their original names and meaning.

## 更新内容

- 支持中文（普通话）、英语、日语、韩语、俄语五种语言之间20个有向在线语音翻译方向，按实际源/目标语言直接翻译。
- 日语、韩语、俄语明确标为 Beta 实验性语言；源/目标选择统一显示 Beta 标签，并按识别/译文方向显示非阻断说明。标签不改变语言代码或内部 ASR 策略。
- 软件界面新增日语、韩语、俄语，覆盖设置、浮窗、首次配置、模型下载、更新、错误提示及帮助；界面语言独立于翻译方向保存。
- 中文译其他语言时，识别原文在浮窗和手机镜像中显示简体，保留原始 ASR、送翻译文本和实际译文。
- 日语、韩语内部使用兼容识别策略；俄语在极速、非极低影响模式下使用既有语音完整性策略。正式界面不提供策略开关，标准、精准及自定义调校保留原逻辑。
- 日/韩/俄相关方向需要用户自行配置在线 Provider；本地 OPUS 继续仅支持英中双向，不自动回退到其他语言或收费服务。英语专用 `.en` 模型不会用于非英语识别。
- 语言切换清理旧方向任务和音频，过期结果不会覆盖当前字幕；翻译输出达到长度上限时提示不完整，不展示或提供复制截断正文。
- 切换识别模型后，后台自动检查缓存、下载或加载；无须等待下一段语音，暂停时仍可准备，显示持续的模型准备状态。
- 保留现有英中识别、离线 OPUS、正式 ASR 预设和翻译 Prompt；不集成日/韩/俄离线 PoC，不增加降噪、音源分离、OCR 或官方付费服务。
- Full 匿名诊断按 Fast/Balanced/Accurate/Custom 分类统计 ASR；在线翻译失败按固定原因和服务商分类，对应 Dashboard 展示。历史未分类数据不回填，63字段协议及授权规则不变，不上报语音、字幕、Key或请求地址。

多语言质量依赖实际音频与用户配置的服务商/模型。既有公开朗读测试和 AI 辅助审阅不等于双语人工或真实游戏验收；本地打包不代表这些验收项已完成。

### 已知限制（Beta）

- 短句、连续语音切段、噪声和多人重叠可能造成漏词、句尾丢失或语言误判；日语已有整段无译前文本的个例，尚无证据证明已通用修复。
- 在线翻译仍可能改变楼层、角色、数量、否定或行动时序；Provider/模型能力不同，不能将技术接通视为语义人工验收。
- 在线超时与排队会增加字幕延迟，复杂语音和较大识别模型会增加 CPU/内存占用。真实游戏 FPS、低配实机和双语人工验收仍待完成，不承诺准确率或延迟数值。
- 离线 OPUS 仅英中双向。日/韩/俄相关的其他18方向需用户自行配置在线服务；不集成多语言离线 PoC。

## What's new

- Supports 20 directed online speech-translation pairs across Mandarin Chinese, English, Japanese, Korean and Russian, translating directly between the selected languages.
- Japanese, Korean and Russian are explicitly experimental Beta languages. Both language selectors show Beta labels and a non-blocking recognition/translation notice, without changing language codes or internal ASR strategies.
- Added Japanese, Korean and Russian interface languages across settings, the overlay, setup, model downloads, updates, errors and help. Interface language is saved independently of translation direction.
- Chinese source transcripts display in Simplified Chinese in the overlay and mobile mirror. Raw ASR, translation input and real translated output are preserved.
- Japanese and Korean internally use compatibility recognition. Russian uses the existing speech-completeness policy in Fast mode except Ultra Low impact. Settings has no strategy switch; Balanced, Accurate and Custom behavior is retained.
- JA/KO/RU directions require a user-configured online provider. Offline OPUS remains English–Chinese only, without silent provider substitution. English-only `.en` models are restricted to English recognition.
- Language changes cancel and isolate old tasks/audio so stale results cannot replace current subtitles. Length-limited translations show an incomplete-output notice without displaying or copying partial output.
- Changing the recognition model starts a background cache check, download or load without waiting for speech, including while paused, with persistent preparation status.
- Preserves existing English–Chinese recognition, offline OPUS, formal ASR presets and translation prompts. No experimental offline languages, denoising, source separation, OCR or official paid API service is added.
- Full anonymous diagnostics classify ASR by Fast/Balanced/Accurate/Custom and API failures by fixed reason/provider, with matching Dashboard views. Historical data is not inferred or backfilled; the existing 63-field protocol and consent rules are unchanged. No audio, captions, keys or request addresses are uploaded.

Multilingual quality depends on the audio and configured provider/model. Public read-speech results and AI-assisted review do not constitute bilingual human or real-game acceptance; a local package build does not complete those checks.

### Known limitations (Beta)

- Short phrases, continuous-speech segmentation, noise and overlapping speakers can cause missing words, lost sentence endings or language misclassification. One Japanese recording produced no translation input; a general fix has not been demonstrated.
- Online translation can still change floor levels, roles, quantities, negation or action order. Quality varies by provider/model; routing success is not bilingual human acceptance.
- Timeouts and queues add subtitle latency; complex speech and larger recognition models cost CPU and memory. Real-game FPS, low-end hardware and bilingual human acceptance remain pending. No accuracy or latency guarantee is claimed.
- Offline OPUS is English–Chinese only. The other 18 directions involving Japanese, Korean or Russian need a user-configured online service; no multilingual offline PoC is integrated.
