# v0.6.0：API 提醒收口与模型主动准备

基线 `506d0962`，分支 `codex/release-0.6.0`。按用户截图反馈修复两项交互；不调整 ASR 模型选择、参数、切段、Prompt、过滤阈值、英中 OPUS 或63字段协议。

## API / 本地提示

`_translation_language_notice` 对有效在线方向返回空提示；API 浮窗与设置页不再重复提示“需自配 API Key”，也不误用离线模型说明。离线不支持的方向继续说明仅英中离线可用、其他方向需自行选择在线服务；没有自动回退。无效在线方向仍显示能力错误。测试覆盖两种在线 Provider、20方向、五种界面语言，以及 Provider 切换后的提示显隐。

## 选定模型后主动下载或加载

原 `SpeechRecognizer.request_config` 只记录配置，下一次有语音时才应用和初始化。现在保存设置后向**原 speech-worker** 发送独立准备请求：

- 空闲或翻译暂停时也准备，不需要语音，不伪造 SpeechSegment，不占音频队列槽位或增加 ASR 片段统计。
- 正在识别、加载或下载时等待当前任务完成，在同一线程顺序处理；不新建并行模型加载线程，不中断原生推理。
- 连续待处理请求合并为最新配置；已有相同原生配置不重新加载。当前下载已经开始时不强行终止 HTTP/原生调用。
- 设置控制器先清理旧方向队列/版本，再提交准备请求，避免重复预热及旧任务争用。旧版本音频在 Whisper 前丢弃；音频快照不会吞掉较新的待应用配置。
- 失败后工作线程保持可用，不在无新请求时无限重试；退出优先于待准备任务，保持停止后空队列契约，活跃线程未结束时不清理模型。

主要位置：`VoxGoApp._queue_recognizer_config`、`OverlaySettingsController.apply`、`SpeechPipeline.request_model_preparation/_worker/stop`、`SpeechRecognizer.prepare_pending_config/_apply_pending_config`。待准备提示改为“将自动检查缓存并下载或加载模型”，覆盖五种界面语言。
