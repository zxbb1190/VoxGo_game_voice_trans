# v0.5.1 experience checks

Scope: audio-device recovery, visible overlay placement, provider label, hover
copy, and first-run system language only. No new ASR/translation behavior or
telemetry categories are introduced.

Automated validation on 2026-09-23: all 395 unittest tests passed (30.387s).
`python -m compileall -q voxgo tests scripts main.py` and `git diff --check`
passed. A read-only Windows Core Audio probe returned a default endpoint and
five active output endpoints; no hardware unplug/reconnect was simulated.

Windows hardware acceptance (still required):

- While translating, unplug/reconnect USB audio, disconnect/reconnect Bluetooth,
  and change HDMI/default output. Check recovery notices, restored capture,
  bounded retry failure, UI responsiveness, and exit during recovery. Check an
  explicitly selected device never changes just because another default changes.
- Unplug a secondary monitor, change resolution/scaling, and reconnect Remote
  Desktop. Check the overlay returns to a visible work area; tray Reset Overlay
  Position must show it without changing its game-friendly window flags.
- Change between API, Google, and Local in Settings; verify the short toolbar
  label immediately updates in both UI languages and compact mode, with no URL
  or credentials exposed.
- Hover a completed subtitle, click Copy, and paste into a text editor. Verify
  only translated text is copied, the button disappears on leave, and pending,
  error, and status rows have no copy button. Check locked-overlay behavior.
- In a clean directory, test zh_CN/zh_TW versus zh_HK/zh_SG and other locales.
  Restart with a different system language and confirm the saved UI language is
  retained. Repeat with existing user_settings.json and completed setup.

Automated coverage uses fake capture devices, controlled blocking open/retry
operations, real offscreen Qt widgets/clipboard, fake monitor geometries, and
temporary persisted configuration. These checks cannot certify native device
drivers, monitor hotplug, tray behavior, or exclusive-fullscreen game focus.
