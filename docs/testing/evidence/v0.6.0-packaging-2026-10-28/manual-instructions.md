# VoxGo v0.6.0 手动测试

请先正常退出旧版，避免音频、端口和快捷键冲突，再双击本目录的 **Start-VoxGo.cmd**。它运行同一份正式 Full EXE，仅使用本目录独立配置，不覆盖原安装、设置或模型。

- 已关闭 Full 遥测和自动更新。启动器还通过进程专用代理阻断遥测域名，Basic 也无法外传；请始终从启动器启动，不直接双击子目录 EXE，不开启 Full。生产0006/兼容Worker尚未部署验收。
- 未复制真实 API Key。在线测试时请在本包设置中自行填写。默认硅基流动 tencent/Hunyuan-MT-7B；启动器只放行硅基流动、Google、OpenAI官方及本机地址。自定义域名需加入启动器 NO_PROXY。
- 已复用并校验本机 base/small 及英中 OPUS 缓存，未增加日/韩/俄离线模型。启动器保持模型离线，避免意外下载。
- 独立配置跳过首次向导以保持遥测拒绝；首次安装向导仍需另验。

## 建议顺序
1. 关于页核对0.6.0；切换简中/English/日本語/한국어/Русский，检查设置、浮窗和提示。
2. 核对多语在线提示没有“质量未完成验收”尾句，语音设置没有“完整性策略”开关。
3. 中文译其他语言时核对原文显示简体；日/韩兼容，俄语极速、非极低影响时内部采用既有完整性策略。
4. 先测英中双向离线，再手动配置在线服务。检查五种源语言及各自四种目标、交换、保存重启恢复。
5. 有请求时切换语言，检查无旧方向新字幕；检查缺Key、错误提示、暂停恢复和正常退出。
6. 如方便，在固定游戏场景比较开启前后FPS、卡顿和字幕延迟；真实游戏、低配与双语人工语义验收仍待完成。

本轮自动化没有调用真实翻译API。ZIP、代码/字典/模型校验及启动导入检查，与完整GUI、物理音频和质量验收分开记录。首次手测无需重新下载模型。
