## 播放步骤

1. 使用根目录内的独立候选启动入口。先确认隔离配置、遥测不发往生产且当前使用受控本地 Provider；本轮不要粘贴或启用真实在线 API Key。
2. 关闭其他音频，选择 Windows 当前播放输出设备对应的系统声音回环；候选程序选择日/韩/俄 → 中文及多语言 Whisper，启动监听。
3. 双击对应 WAV，使用 Windows 自带媒体播放器播放。也可以在 PowerShell 执行下例（不安装软件）：

```powershell
$audioFile = 'E:\my\my\VoxGo-0.5.3-Acceptance-caed9130\materials\ja-10214476888438240131.wav'
$player = New-Object System.Media.SoundPlayer $audioFile
$player.PlaySync()
```

4. 每段播一次，等待字幕或错误提示后停下来记录。记录 Whisper 实际识别、检测语言、过滤原因、Provider 请求是否被阻止/受控、浮窗实际文字与时间。受控翻译只能证明传输/GUI 显示，不能作为译文质量证据；空 Key 只能检查错误提示。当前没有本轮授权的在线真实翻译结果。
5. 三语分别执行，跨语言切换后再播放一次，确认没有上一种语言的旧字幕误入。用 `manual-review.csv` 填表；波形末帧到字幕显示必须注明测量方式，不能将 API 耗时或分段耗时直接称为屏幕端到端延迟。
