# 俄语独立基线之后：下一步决策

依据仅为本轮新取得的 16 条 MInDS-14 语音、12 条 MUSAN 负样本及其 56 次离线运行，详见 [基线报告](ru-continuous-baseline-2026-10-27.md)。不沿用旧 FLEURS 两条录音选择参数。正式运行时维持 `645c6ace`；本轮没有选定新算法。

## 对六个问题的回答

| 问题 | 本轮证据 | 决策 |
|---|---|---|
| 切段是否最常见问题？ | 强制切段 dev 43→26，PCM 无重复提交/重排；仍有未覆盖区间，但缺逐词帧真值。新样本存在 raw 异语/重复、否定词差异及地名疑似错误 | **不能排序语义根因频率**。切段数减少不是切段错误减少；完整音频收到与否需要人工帧标签证明 |
| 过滤误杀是否普遍？ | 预算拒绝分布于 12/16、7/16 条 dev；ASR 后拒绝 11、14 段。负样本也被大量拒绝 | 只能确认拒绝行为普遍存在，**不能确认普遍误杀**；需同时核实被丢弃语音和被放行噪声 |
| 是否开发通用短尾段保留？ | 本轮未建立人工短尾段组，没有“有效尾音被拒绝”的数量或语义损失率 | **暂不开发**；不能用旧样本或句尾三词差异决定恢复机制 |
| 是否先修预算与队列？ | dev 队列等待 P95 约 1ms，无 raw queue 丢块/未排空；negative legacy P95 640ms。预算拒绝可由 cooldown/stale 引起 | 尚无队列积压为主因的证据，也没有放宽预算的收益/误触发证据；保持现状 |
| 候选相对 legacy 有可靠收益？ | 译前临时 CER/WER 33.94/54.52%→26.43/41.21%；ASR P95 1.692→1.059s；CPU/音频分钟 +9.9%。个别录音退化，raw 重复噪声仍出现 | 只有窄领域探索性改善，**无人工语义/独立说话人 holdout/游戏泛化证据**，不能升级为可靠发布收益 |
| 最值得实施的最小代码改动？ | 已有 267 项未填写人工审阅表；现有自动指标不能判定有效语音误杀或噪声幻觉 | **仅扩展离线评测工具，接入人工逐词帧及语义标注 sidecar**。当前没有证据支持一个正式识别行为改动 |

## 只推荐一个开发方向：人工声学对齐标注接入

范围限 `scripts/ru_benchmark_metrics.py` 与 `scripts/review_ru_continuous_baseline.py`，复用当前 `human-review-items.json`；不新增 Whisper 调用、不改 `voxgo/`、不自动修参考文本。

具体最小功能：导入人工 sidecar，强制绑定 `dataset_id + recording_id + PCM SHA256 + 原 WAV 帧区间`，记录 reviewer、参考转写完整覆盖状态、speech_present、逐词帧、实体/数字/否定/关系/句尾和严重程度；哈希/边界不匹配或 reviewer 缺失则拒绝提升为人工真值。先做词/帧与已保存切段的机械交集，报告人工确认内容在 Capture 未覆盖、预算拒绝、ASR raw 缺失、后过滤丢失、最终译前保留的阶段。无对齐依据的情况仍为 unresolved，跨段关系标为 Context，不能强行指定 Whisper 根因。

第一轮人工材料优先取本轮 **全部预算拒绝片段、全部非空 raw 后过滤片段、`0110/0428/0505` 全录音和全部 12 条负样本**，听完整源音频再定位片段。既有评分只用于安排审阅，不作为自动答案。负样本须确认是否确实没有可懂语音；若有真实背景语音，应重新标签，而不是算作幻觉。保持原冻结 Manifest 和原事件只读，人工标注与新汇总写入新目录。

可验证产出：人工标注覆盖数/独立录音数；有效语音识别前误杀数、已正确识别后误过滤数、人工确认噪声放行数；实体/否定/数字/句尾按适用样本分别统计；Capture/Whisper/Pipeline/Context 的**有证据根因数量**及 unresolved 数量。分母不能含未标注项目，不把重放数当样本数。此工具改动自身不增加 ASR 成本，能直接复算已保存事件。

风险是人工错误或把跨片段参考强行分配给单片段；用完整源音频、帧范围校验、审阅身份与版本追踪约束，允许争议标签。回退只需不传 sidecar，保留现有 pending 与临时编辑距离。添加侧文件哈希错配、越界、无 reviewer、跨段覆盖/否定词、正负样本未标注分母等工具测试。**不要用标注内容给运行时补词、关键词白名单或放宽阈值。**

## 仍缺的资源与停止条件

- 当前 8 条 quarantine 不得直接改名为 locked_holdout；需要可靠的说话人/源会话证据。现有 dev 身份无法补证时，应另建全套身份可核验且按说话人分开的数据版本，将本轮保留为探索集。
- 需要俄语人工听音/转写与语义评审，以及新授权的真实连续发言、多人/快速/噪声语音、短尾音、数字、实体、否定与关系材料；本轮公开银行语料不承担游戏验收。
- 如果人工确认噪声漏放，后续任何召回改动都必须同时报告噪声放行的变化；不能只看 CER 改善。如果无法完成词帧对齐或身份隔离，应停止对正式策略的收益外推，继续保持未验收状态。
- 后续算法候选只有在新的、未参与调参且身份隔离的验收录音上通过关键语义及性能检查后才考虑集成；具体错误/性能阈值需另行确立，本报告没有创造已批准的发布门槛。

当前判断：**评测机制可复用；新样本观察已成立；语义根因分布、充分泛化证据和发布标准均未完成。** 不继续对旧两条录音调参，不启动专用上下文恢复机制。
