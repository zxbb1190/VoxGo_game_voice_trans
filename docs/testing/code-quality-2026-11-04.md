## 异常输出修复与复验（2026-11-11，后续实施）

针对上节发现的问题，按确认范围实施了两处保护：

- 重复文本保护：至少 24 个词、连续重复覆盖至少 20 个词且占全文至少 80%，
  同一词至少连续重复 12 次或同一多词短语至少连续重复 8 次时，不再要求词速达到 8 词/秒。
  普通重复仍保留原有词速条件；短口令不达到长文本门槛。
- 异常译文保护：结果主要由明确的未知字符／解码占位符 `⁇`、`�`、`<unk>` 组成时，
  转为现有失败提示，隐藏异常正文，不计入成功翻译，也不能通过离线接口测试。
  当前配置、配置快照、短语缓存和运行时输出均经过同一规则；桌面与手机只收到失败提示。
  普通问号、游戏代码和正常文本中偶发的未知字符保留。

未修改语言概率阈值、音量阈值、模型路由或推理参数，也未增加识别重试。
复验覆盖率时发现 Python 3.10 读取 TOML 配置缺少可选依赖，测试依赖已改为
`coverage[toml]==7.16.2`，避免新的 CI 环境无法读取 `pyproject.toml`。
