## 用户手测清单

1. 退出旧 VoxGo，完整解压本次 ZIP，按原有便携升级方式保留自己的设置和模型。
   仅运行一个实例，确认使用的是本次 SHA256 对应的包。
2. 在隐私页确认原 Full 开关勾选。现在没有语言统计的第二开关；原来关闭过的设置不会被强开。
3. 使用实际浮窗字幕翻译，先各测少量中/英/日/韩/俄源语言，再切换几个不同目标。
   设置中的“测试翻译”和单纯切换语言不算使用；短语缓存单列，不算真实 API 使用。
4. 等本地约30秒刷盘，再观察一次上报。默认约15分钟一轮，保持程序打开；退出不强制上传。
5. 在 EXE 所在目录的 `analytics-remote/<当前授权目录>/` 查看 `debug-state.json`：
   成功应为 `last_result=acknowledged`，不能只凭 HTTP200判断。方向计数应与实际任务匹配。
6. 完成日语言 Dashboard 不包含今天。当天先看本地计数/ACK及实际入库；跨下一次北京时间
   08:00后核对完整 UTC 日。录音可被分成多项任务，不按播放次数强行对齐计数。
7. 最后测试原 Full 开关关闭，确认不再产生后续 Full 上报；不要删除累计文件来“清零”测试。

本轮生产没有注入测试事件，所以当前没有语言上报并不表示新功能失效。请保留测试方向、
模式及时间；排查时仅提供必要的固定状态字段，不分享Key、语音、原文或完整授权/汇总文件。
