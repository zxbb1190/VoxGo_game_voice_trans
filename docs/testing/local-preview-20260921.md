# 2026-09-21 本地 Telemetry 手测

按用户最新决定，不创建 staging，改为本地预览包手动测试。
Production TELEMETRY_ENABLED 保持 false。本轮不向生产发送合成或真实统计。

包名：VoxGo-v0.4.3-preview-telemetry-20260921-lite.zip。
这是便携测试包，不是正式发布。程序内部版本仍为0.4.2；未改动正式发布版本。
Lite 不含预装模型/独立 CUDA 运行库，使用API或下载模型后测试翻译。

1. 解压到独立新目录，运行 VoxGo.exe，不覆盖日常使用目录。
2. 首次向导不勾选统计授权：正常启动、翻译、暂停、恢复，隐私默认关闭。
3. 在设置中明确授权：允许后台请求 /v1/config，但服务端关闭时不得 POST 快照。
4. 连续翻译，检查 analytics 与 analytics-remote 中仅出现数字汇总，不包含文本或密钥。
5. 断网后翻译UI保持响应；恢复网络后重试遵守后台间隔，不反复弹错。
6. 撤回授权，重启：保持关闭。再次授权使用新标识，不补传旧授权数据。
7. 翻译运行时退出：不能为了上报卡住退出。仍按原生命周期关闭/托盘选项手测。
8. 如测试环境阻断API，检查界面是否依然可操作，关闭程序是否仍能及时完成。

现有Windows全量280项测试通过。实际上传写入、D1确认及生产访问限制尚未端到端验证；
本地手测和服务端关闭情况下的测试不能替代这些结果。正式启用前需另行明确授权并验证。
