# 窗口关闭与托盘生命周期验证

日期：2026-09-15。开发改动，尚未正式发布。

## 行为

- 关闭主浮窗先选择最小化或退出，取消不改变状态；记住选择后可在设置中改回每次询问。
- 最小化保留当前运行／暂停状态。托盘不可用时不隐藏主浮窗。
- 退出首先阻止新翻译并取消已提交的异步任务，再在后台清理音频、语音识别、手机服务和翻译资源。
- 原生模型推理不能强行中断；清理失败或超过 20 秒时保留托盘和恢复弹窗，允许重试或确认强制退出当前进程。已发出的请求可能仍由服务端计费。

- 使用真实 Windows Qt 桌面后端创建主浮窗和托盘，托盘图标非空且系统返回了有效图标矩形。
- 真实关闭确认弹窗选择最小化并勾选记住，确认行为已保存且浮窗隐藏。
- 最小化隐藏浮窗，托盘菜单恢复浮窗。
- 注入一次音频清理失败，确认翻译暂停、托盘和恢复弹窗保留；再次退出清理成功。
- Lite 便携包构建成功，独立启动便携程序，通过主浮窗 WM_CLOSE 触发记住的退出行为，进程退出码为 0。
- 自动定位主浮窗必须结合窗口大小：小型锁定按钮与主浮窗具有相同窗口标题，不能只按 `VoxGo` 标题选择句柄。

这些结果验证本机 Windows 环境。Windows 通知区域可能折叠图标；尚不能代表反馈者电脑上的托盘显示行为。
