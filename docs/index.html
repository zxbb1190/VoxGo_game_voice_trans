  • 可测试翻译接口

  • 无须配置 API Key
  • 模型按需下载
  • 识别与翻译可在本机完成

常见问题

把用户最担心的问题先说清楚，可以减少误解，也方便你收集更高质量的测试反馈。

VoxGo 能实时翻译外国队友语音吗？

可以。VoxGo 捕获游戏或 Discord 的系统声音，将英语和中文语音识别并显示为实时字幕。

支持本地翻译模式吗？

支持。选择本地翻译模式后无需配置 API Key，按提示准备模型即可使用。

它会录我的麦克风吗？

默认目标是捕获 Windows 系统声音输出，不是麦克风。设置里应优先选择 [系统声音] / Loopback 设备；普通麦克风通常录不到游戏声音。

会不会注入游戏进程？

不会。它是独立桌面程序，通过系统声音设备采集音频，并用透明置顶窗口显示字幕，不修改游戏客户端。

为什么没有字幕？

通常是音频设备没选对，或者游戏 / 微信 / Discord 声音走了另一个输出设备。先在向导或设置里测试音频，看音量条是否跳动，再确认 Windows 音量混合器里的输出设备和工具里选择的 Loopback 设备一致。

为什么识别不准？

真人语音比视频更难识别，尤其是短句、口音、噪声、背景音乐和压缩音频。英文竞技游戏优先试“极速/游戏性能 + 纯英文环境”；如果语音经常中英混杂，请关闭纯英文环境。

支持哪些语言？

当前正式支持英语和中文双向：英语 → 中文、中文 → 英语。其它语言暂未在界面和识别/翻译流程中开放为可选项。

Lite、Full 和 Full-CUDA 有什么区别？

Lite 不带模型也不带 CUDA DLL，体积最小；Full 带 Whisper small/base 通用模型但不带 CUDA DLL；Full-CUDA 同时带通用模型和 CUDA DLL，给 NVIDIA 用户单独下载。英文专用模型只在开启纯英文环境后按需下载。

支持哪些游戏？

只要游戏语音能从当前扬声器、耳机、HDMI、USB 声卡或虚拟声卡正常播放，并且系统能暴露对应 Loopback 设备，就可以尝试。未逐个实测的游戏不应标记为已兼容。

报告可复现的技术问题

遇到可复现的 Bug，可通过设置里的提交反馈模板附上版本、音频设备、翻译服务、最近延迟和日志路径；使用交流和功能建议欢迎到社区讨论。
